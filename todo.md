# Checklist Kesesuaian Tugas

- [ ] Verifikasi isi kriteria pada screenshot tugas secara penuh.
- [ ] Cek apakah website menunjukkan penerapan konsep PBO Bab 4 secara eksplisit.
- [ ] Cek apakah terdapat bukti penggunaan Git: init, add, commit, branch, dan push.
- [ ] Cek apakah repository GitHub sudah tersedia dan berisi kode terbaru.
- [ ] Tambahkan atau perjelas bagian PBO bila website baru menampilkan konsep web/Git secara umum.
- [ ] Jalankan pemeriksaan akhir sebelum pengguna mengumpulkan tugas.
