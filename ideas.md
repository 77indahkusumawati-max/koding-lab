## Pendekatan Terpilih: Visual Learning Lab

### Design Movement
Contemporary educational editorial design yang memadukan Swiss-inspired information design, flat illustration, dan presentasi Canva yang terstruktur.

### Core Principles
1. Satu ide utama per bidang visual, dengan ruang negatif yang cukup untuk menjaga fokus.
2. Kontras fungsional: navy untuk struktur, magenta untuk energi, mustard untuk momen penting, dan charcoal untuk materi kode.
3. Layout asimetris dua kolom agar terasa seperti rangkaian slide yang bisa dijelajahi, bukan landing page generik.
4. Setiap elemen dekoratif harus membantu orientasi belajar: nomor bab, node alur, dot pattern, atau penanda progres.

### Color Philosophy
Navy (#192A4A) memberi rasa stabil dan tepercaya sebagai fondasi belajar. Magenta (#D94F86) menjadi aksen yang berani untuk menandai aksi dan ide baru. Mustard (#F2C14E) digunakan hemat seperti highlighter pada catatan. Off-white (#F8F7F3) menjaga halaman tetap lapang, sedangkan charcoal (#161A22) membuat code snippet terasa seperti jendela kerja yang fokus.

### Layout Paradigm
Struktur halaman mengikuti “scrolling lesson deck”: hero dengan split composition, bab-bab berurutan, visual flow Git yang melebar lintas kolom, lalu area code lab. Konten tidak selalu dipusatkan; ilustrasi, nomor bab, dan garis navigasi diletakkan offset untuk menciptakan ritme editorial.

### Signature Elements
1. Nomor bab besar dengan garis vertikal sebagai penanda progres.
2. Pola titik dan garis diagonal tipis sebagai tekstur latar.
3. Kartu “concept chip” berbentuk pil pendek yang muncul di samping penjelasan teknis.

### Interaction Philosophy
Interaksi terasa seperti membuka catatan belajar: hover mengangkat kartu sedikit, klik pada node Git mengubah panel penjelasan, dan tombol copy memberi umpan balik singkat tanpa mengganggu alur.

### Animation
Gunakan reveal lembut 180–260ms dengan cubic-bezier(0.23, 1, 0.32, 1). Node workflow muncul berurutan 60ms. Hover hanya mengubah transform, opacity, dan shadow. Hormati prefers-reduced-motion dengan menonaktifkan animasi non-esensial.

### Typography System
Display: Space Grotesk, 700–800, untuk judul dan angka bab. Body: DM Sans, 400–600, untuk keterbacaan. Code: JetBrains Mono, 400–600, untuk snippet dan label teknis. Headline memakai sentence case tegas, bukan all-caps berlebihan.

### Brand Essence
Koding Lab adalah ruang belajar web development untuk pemula yang ingin memahami sistem lewat visual, bukan hafalan; berbeda karena materi teknisnya dibangun seperti peta yang bisa dijelajahi. Personality: terstruktur, hangat, eksploratif.

### Brand Voice
Headline dan CTA terdengar langsung, suportif, dan konkret. Hindari jargon kosong.
- “Pahami alurnya. Baru tulis kodenya.”
- “Telusuri dari commit pertama sampai deploy.”

### Wordmark & Logo
Mark berupa simbol simpul tiga titik yang dihubungkan satu garis membentuk huruf K abstrak; wordmark “KODING LAB” ditata dengan tracking rapat dan kontras bobot, bukan font default.

### Signature Brand Color
Magenta Koding #D94F86.

## Reference Synthesis
Ketiga video memperlihatkan pola yang konsisten: edukasi teknologi dengan gaya flat illustration, ruang putih besar, komposisi teks-ilustrasi dua kolom, judul tebal sans-serif, kode dalam panel gelap, serta transisi sederhana. Website akan menerjemahkan pola tersebut menjadi pengalaman interaktif, bukan menyalin frame atau identitas visual video secara literal.
